# SceneSplat SLAM Integration — Implementation Reference
# This file documents the complete SceneSplat integration into ActiveSGM.
# Use this as the sole reference when modifying the implementation.

================================================================================
OVERVIEW
================================================================================

SceneSplat replaces OneFormer 2D image segmentation (used in SemSplatam) with a
3D Point Transformer V3 (PTv3) model that operates directly on the Gaussian splat
point cloud. Instead of running a 2D segmentor per-frame, SceneSplat runs on the
full Gaussian map after each mapping step, producing per-Gaussian 16-dim semantic
features via an autoencoder (768 → 16 dim compression).

Key differences from SemSplatam:
- No per-frame semantic annotation (no OneFormer)
- No semantic loss during tracking/mapping (features are directly assigned)
- Features are 16-dim autoencoder latent (not 102-class logits)
- SceneSplat runs after mapping steps, not per-frame
- ~15x faster than SemSplatam due to no per-frame model + no semantic loss

(sparse_channel_rasterization) but has no semantic loss.

SCENESPLAT.PY — MAIN CLASS (SceneSplatam)
================================================================================

File: src/slam/scenesplat/scenesplat.py
Class: SceneSplatam(SplatamOurs)

Imports from different eval_helper than SemSplatam:
  - Uses: src/slam/splatam/eval_helper.py (base)
  - NOT:  src/slam/semsplatam/modified_ver/splatam/eval_helper.py

  CRITICAL: Function signatures differ between these two eval_helpers:
    BASE (what we use):
      report_progress(params, data, i, progress_bar, iter_time_idx, sil_thres, ...)
      eval(dataset, final_params, num_frames, eval_dir, sil_thres, ...)
      save_params_ckpt(output_params, output_dir, time_idx)
    SEMSPLATAM (NOT used):
      report_progress(slam_model, params, variables, data, i, progress_bar, ...)
      eval(slam_model, dataset, params, variables, num_frames, ...)
      save_params_ckpt(output_params, output_variables, output_dir, time_idx)

  DO NOT add `self`, `variables`, or extra args to these calls.

Key methods:

  __init__(main_cfg, info_printer, logger):
    - Calls SplatamOurs.__init__
    - Loads PTv3 backbone via load_scenesplat_backbone()
    - Loads Autoencoder via load_autoencoder()
    - Sets self.n_cls=16, self.topk=16, self.scenesplat_grid_size=0.02

  run_scenesplat_on_map():
    - @torch.no_grad()
    - Runs run_scenesplat(backbone, autoencoder, params, grid_size, device)
    - Overwrites params['semantic_logits'] with torch.nn.Parameter(feat_16)
    - Sets variables['seman_cls_ids'] = arange(16).expand(N, 16) (identity)

  init_camera_parameters():
    - Calls initialize_first_timestep() (no seman arg)
    - Then run_scenesplat_on_map() on initial Gaussians

  online_recon_step(time_idx, color, depth, c2w, ...):
    - NO per-frame semantic annotation
    - Calls update_gs_map() then update_explr_map()

  update_gs_map(time_idx, color, depth, c2w, ...):
    - Tracking: uses get_loss() (base, geometry-only: RGB + depth)
    - Mapping: uses get_loss() (base, geometry-only)
    - Densification: add_new_gaussians_with_seman() — new Gaussians get zero semantics
    - Pruning: prune_gaussians_w_semantic() — maintains semantic_logits consistency
    - After mapping loop: run_scenesplat_on_map() enriches ALL Gaussians

  render(c2w) -> (im, depth, valid_mask, seen):
    - Standard RGB+depth rendering via diff_gaussian_rasterization

  render_semantic(c2w, seen) -> (class_id, logits):
    - Renders 16-dim features via sparse_channel_rasterization
    - class_id = logits.argmax(dim=0)

  print_and_save_result():
    - Uses base eval() for RGB-only evaluation (no semantic eval)
    - Saves params including seman_cls_ids

  load_params_by_step(step, stage):
    - Loads checkpoint, pops seman_cls_ids into variables

Star import: `from src.slam.splatam.modified_ver.scripts.splatam import *`
  - Provides get_loss used in tracking/mapping
  - This shadows the get_loss from third_parties.splatam.scripts.splatam
    (harmless — same function forwarded)

get_loss signature (from star import):
  get_loss(params, curr_data, variables, iter_time_idx, loss_weights,
           use_sil_for_loss, sil_thres, use_l1, ignore_outlier_depth_loss,
           tracking=False, mapping=False, ...)

================================================================================
SCENESPLAT_MODEL.PY — PTv3 + AUTOENCODER
================================================================================

File: src/slam/scenesplat/scenesplat_model.py

Contains: Autoencoder class, load_scenesplat_backbone(), load_autoencoder(),
          _voxel_downsample(), prepare_gaussian_input(), run_scenesplat()

Autoencoder:
  - Copied from /mnt/Data2/liyan/SceneSplat/autoencoder/model.py
  - Only encoder is used (encode: 768 → 16, L2-normalized)
  - encoder_hidden_dims = [512, 256, 128, 64, 32, 16]
  - decoder_hidden_dims = [32, 64, 128, 256, 256, 512]
  - Checkpoint: plain state_dict, loaded directly with load_state_dict()

load_scenesplat_backbone(checkpoint_path, pointcept_path, device):
  - Adds pointcept_path to sys.path for importing pointcept
  - Instantiates PointTransformerV3 with hardcoded config:
      in_channels=11, stride=(2,2,2), enc_depths=(2,2,2,6),
      enc_channels=(32,64,128,256), dec_channels=(768,512,256),
      enable_flash=True, etc.
  - Loads checkpoint, strips "module.backbone." prefix from state_dict keys
  - Returns backbone in eval mode

prepare_gaussian_input(params, grid_size=0.02):
  - Extracts from SplaTAM params:
      coord  = params['means3D'].detach()                        [N, 3]
      color  = sigmoid(params['rgb_colors']) * 255               [N, 3]
      opacity = sigmoid(params['logit_opacities'])               [N, 1]
      quat   = normalize(params['unnorm_rotations']), +real part [N, 4]
      scale  = exp(params['log_scales']), tile to 3 if isotropic [N, 3]
  - Color normalization: color / 127.5 - 1.0 (maps [0,255] → [-1,1])
  - Voxel downsampling via _voxel_downsample (FNV hashing)
  - feat = cat([color_norm, opacity, quat, scale], dim=-1) → [M, 11]
  - grid_coord = floor((coord_ds - coord_ds.min(0)) / grid_size).int()
  - offset = tensor([M]) (single scene, batch_size=1)
  - Returns data_dict and inverse mapping [N] → voxel representatives

_voxel_downsample(coord, grid_size):
  - FNV hash-based voxel downsampling (matches pointcept's GridSample)
  - Primes: 73856093, 19349669, 83492791
  - Returns selected_indices [M] and inverse [N]

run_scenesplat(backbone, autoencoder, params, grid_size, device):
  - @torch.no_grad()
  - Calls prepare_gaussian_input → PTv3 backbone → autoencoder.encode
  - Maps 16-dim features back to all N points via inverse mapping
  - Returns feat_16 [N, 16]

External dependencies:
  - pointcept: /mnt/Data2/liyan/SceneSplat/pointcept/
    - pointcept.models.point_transformer_v3.point_transformer_v3m1_base.PointTransformerV3
    - pointcept.models.utils.structure.Point (used internally by PTv3)
  - Added to sys.path at runtime, NOT copied into project

MODIFIED_VER/SPLATAM/SPLATAM.PY — HELPER FUNCTIONS
================================================================================

File: src/slam/scenesplat/modified_ver/splatam/splatam.py

Adapted from src/slam/semsplatam/modified_ver/splatam/splatam.py with:
- No semantic loss functions (removed calc_hellinger, calc_cosine, calc_kl, etc.)
- No uncertainty masking (removed get_uncert_mask, get_crop_mask)
- Zero-initialized semantic logits (filled by SceneSplat, not by 2D annotation)
- Identity seman_cls_ids (0..15 for all Gaussians)

Functions:

  setup_camera(w, h, k, w2c, near=0.01, far=100, num_channels=16):
    - Creates Camera with num_channels=16 for semantic rendering
    - Uses channel_rasterization.GaussianRasterizationSettings

  initialize_params_with_seman(init_pt_cld, num_frames, mean3_sq_dist,
                                gaussian_distribution, n_cls=16):
    - params['semantic_logits'] = zeros [N, n_cls]
    - variables['seman_cls_ids'] = arange(n_cls).expand(N, n_cls)
    - All params wrapped as torch.nn.Parameter

  initialize_first_timestep(dataset, num_frames, ..., n_cls=16):
    - Does NOT take seman argument (unlike SemSplatam's version)
    - Uses get_pointcloud from base splatam (xyz + rgb only)
    - Calls initialize_params_with_seman

  add_new_gaussians_with_seman(params, variables, curr_data, sil_thres,
                                time_idx, mean_sq_dist_method,
                                gaussian_distribution, n_cls=16):
    - New Gaussians get zero semantic_logits and identity cls_ids
    - Does NOT take seman in curr_data

  initialize_optimizer(params, lrs_dict, tracking):
    - Uses lrs_dict.get(k, 0.0) for missing keys
    - This handles semantic_logits not being in tracking lrs (gets lr=0.0)
    - NOTE: replica_splatam_s.py has semantic_logits=0.0001 in mapping lrs

  transformed_params2semrendervar_sparse(params, transformed_gaussians, seen):
    - Prepares rendervar for sparse semantic rasterization
    - colors_precomp = params['semantic_logits'][seen]

  set_camera_sparse(cam, cls_ids):
    - Wraps cam into Camera_sparse with cls_ids

  prune_gaussians_w_semantic(params, variables, optimizer, iter, prune_dict):
    - Prunes Gaussians AND their semantic data

  remove_points(to_remove, params, variables, optimizer):
    - Removes entries from params, optimizer state, and variables
    - Handles seman_cls_ids and timestep

  densify(params, variables, optimizer, iter, densify_dict):
    - Handles clone AND split cls_ids correctly
    - Clone: extends seman_cls_ids with cloned entries
    - Split: extends seman_cls_ids with repeated entries for split points

================================================================================
DATA FLOW
================================================================================

Frame t arrives:
  → Tracking (geometry-only loss: RGB + depth via get_loss)
  → Mapping (geometry-only loss, densify new Gaussians with zero semantics)
  → run_scenesplat_on_map():
      1. prepare_gaussian_input(params):
         - Extract coords, colors, quats, scales, opacities from params
         - Voxel downsample N points → M voxel representatives
      2. PTv3 backbone(data_dict) → 768-dim features [M, 768]
      3. Autoencoder.encode(feat_768) → 16-dim features [M, 16]
      4. Map back via inverse: feat_16_ds[inverse] → [N, 16]
      5. params['semantic_logits'] = Parameter(feat_16)
      6. variables['seman_cls_ids'] = identity indices
  → Planning/view selection uses render_semantic() with enriched Gaussians

Gaussian parameter shapes:
  params['means3D']:          [N, 3]   positions
  params['rgb_colors']:       [N, 3]   (pre-sigmoid)
  params['logit_opacities']:  [N, 1]   (pre-sigmoid)
  params['unnorm_rotations']: [N, 4]   (pre-normalize)
  params['log_scales']:       [N, 1 or 3] (pre-exp, isotropic or anisotropic)
  params['semantic_logits']:  [N, 16]  (set by SceneSplat, not optimized by loss)
  params['cam_unnorm_rots']:  [1, 4, T] camera rotations per frame
  params['cam_trans']:        [1, 3, T] camera translations per frame

  variables['seman_cls_ids']: [N, 16]  identity (arange(16).expand(N,16))
  variables['timestep']:      [N]      when each Gaussian was created
  variables['n_cls']:         16       number of semantic classes/features

RENDERING PIPELINE
================================================================================

RGB + Depth:
  - diff_gaussian_rasterization.GaussianRasterizer (standard)
  - transformed_params2rendervar → im [3,H,W]
  - transformed_params2depthplussilhouette → depth_sil [2,H,W]

Semantic:
  - sparse_channel_rasterization.GaussianRasterizer (SEMRenderer_sparse)
  - transformed_params2semrendervar_sparse → logits [16,H,W]
  - set_camera_sparse wraps cam + cls_ids into Camera_sparse
  - cls_ids are [N,16] identity indices (all channels used)
  - channel_rasterization used for setup_camera (non-sparse, for cam bg size)

================================================================================
KNOWN ISSUES & CONSIDERATIONS
================================================================================

1. Memory growth: Gaussian count grows over time. SceneSplat processes ALL
   Gaussians each time run_scenesplat_on_map() is called. At ~100K+ Gaussians,
   PTv3 inference spikes can approach 48GB VRAM. Possible mitigations:
   - Reduce SceneSplat frequency (run every N mapping steps instead of every one)
   - Increase grid_size (e.g., 0.05) to reduce input points
   - Add torch.cuda.empty_cache() after inference
   - Chunk inference for very large maps

2. Semantic features are NOT optimized by gradient descent. SceneSplat directly
   overwrites params['semantic_logits'] after each mapping step. The semantic_logits
   lr in replica_splatam_s.py (0.0001) applies during mapping but is overwritten
   by run_scenesplat_on_map() immediately after. This is by design.

3. New Gaussians added during densification start with zero semantic features.
   They are enriched at the end of the mapping step when run_scenesplat_on_map()
   runs on the full map.

4. The voxel downsampling in scenesplat_model.py uses FNV hashing to match
   pointcept's GridSample. After PTv3 inference on downsampled points, features
   are mapped back to all original points via inverse mapping. Points in the
   same voxel share the same features.

5. Color normalization uses color / 127.5 - 1.0 (maps [0,255] to [-1,1]).
   This differs from pointcept's NormalizeColor transform which uses dataset
   mean/std, but matches the effective normalization used during SceneSplat
   training on Gaussian splat data.

================================================================================
COMPARISON: SemSplatam vs SceneSplatam
================================================================================

| Aspect                  | SemSplatam (OneFormer)           | SceneSplatam (SceneSplat)        |
|-------------------------|----------------------------------|----------------------------------|
| Parent class            | SplatamOurs                      | SplatamOurs                      |
| Model input             | 2D RGB image per frame           | 3D Gaussian point cloud          |
| When model runs         | Every frame (semantic_annotation)| After mapping steps (per-map)    |
| Feature dim             | 102 (ADE20K classes)             | 16 (autoencoder latent)          |
| Supervision target      | Rendered seman vs oneformer logits| Direct assignment to params     |
| Semantic loss           | Yes (cosine + Hellinger + KL)    | None (direct overwrite)          |
| Sparse representation   | topk=16 of 102 classes           | all 16 features (trivial sparse) |
| Class IDs (seman_cls_ids)| used to index into 102 classes  | 0..15 (identity, always full)    |
| GPU device              | semantic_device (e.g. cuda:1)    | same device as SLAM              |
| eval_helper imports     | semsplatam/modified_ver/splatam/ | splatam/ (base)                  |
| Speed                   | ~1x (baseline)                   | ~15x faster                      |
