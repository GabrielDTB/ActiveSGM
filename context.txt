================================================================================
GOAL
================================================================================
Create a new SLAM method `scenesplat` (at src/slam/scenesplat/) modeled after
`semsplatam`, but replacing the OneFormer 2D image segmentation model with
SceneSplat — a 3D Point Transformer V3 (PTv3) model that operates directly on
Gaussian splat point clouds to produce per-Gaussian language/semantic features.

================================================================================
SEMSPLATAM SEMANTIC PIPELINE (ONEFORMER)
================================================================================

1. Per incoming frame:
   semantic_annotation(image: Tensor[H,W,3])
     -> input_img converted to PIL Image
     -> oneformer_segmentation(image, processor, model, device, num_classes=102)
     -> returns (class_ids[H,W], logits[H,W,102])

2. logits (H,W,102) are used as `seman` in:
   a. initialize_first_timestep(dataset, seman, ...) — init first Gaussians
   b. add_new_gaussians_with_seman(params, variables, curr_data, ...) — add new Gaussians
   c. get_loss_with_seman(params, iter_data, ...) — semantic supervision loss during mapping
   d. Stored alongside keyframes for re-annotation during mapping iterations

3. Gaussian semantic representation:
   - params['semantic_logits']: [N, TOPK] sparse values (top-k of 102-class logit)
   - variables['seman_cls_ids']: [N, TOPK] column indices (which classes)
   - TOPK = 16 (num_topk_logits in config)
   - num_semantic_classes = 102 (Replica: ADE20K-based OneFormer classes)

4. Semantic rendering:
   - Uses sparse_channel_rasterization (SEMRenderer_sparse)
   - transformed_params2semrendervar_sparse constructs rendervar from sparse logits
   - set_camera_sparse constructs a Camera_sparse with cls_ids

5. Semantic loss (get_loss_with_seman):
   - Compares rendered logits vs GT logits from oneformer
   - Uses combination of: cosine similarity, Hellinger distance, KL divergence
   - Weights: lambda_hel, lambda_cosine

================================================================================
SCENESPLAT MODEL
================================================================================

Checkpoint: /mnt/Data4/scene_splat_7k/checkpoints/
            lang-pretrain-concat-scan-ppv2-matt-mcmc-wo-normal-contrastive.pth

Checkpoint structure:
  keys: ['epoch', 'state_dict', 'optimizer', 'scheduler', 'scaler', 'best_metric_value']
  state_dict keys: prefixed with 'module.backbone.*'
  Architecture: Point Transformer V3 (PT-v3m1) backbone (encoder-decoder)

Model config (from concat_dataset config):
  type: "LangPretrainer"
  backbone:
    type: "PT-v3m1"
    in_channels: 11   # color(3) + quaternion(4) + scale(3) + opacity(1), NO normals
    order: ("z", "z-trans", "hilbert", "hilbert-trans")
    stride: (2, 2, 2)
    enc_depths: (2, 2, 2, 6)
    enc_channels: (32, 64, 128, 256)
    enc_num_head: (2, 4, 8, 16)
    enc_patch_size: (1024, 1024, 1024, 1024)
    dec_depths: (2, 2, 2)
    dec_channels: (768, 512, 256)   # output feature dim = 768 (from dec0)
    dec_num_head: (16, 16, 16)
    dec_patch_size: (1024, 1024, 1024)
    mlp_ratio: 4
    enable_flash: True
    ...

Input format (a `Point` dict from pointcept):
  - "coord":      [N, 3]  xyz positions of Gaussians
  - "feat":       [N, 11] concatenation of color(3) + opacity(1) + quat(4) + scale(3)
  - "grid_coord": [N, 3]  integer grid coords (from GridSample at grid_size=0.02m)
  - "offset":     [B]     batch offsets (or "batch": [N] batch indices)

  feat_keys = ("color", "opacity", "quat", "scale")
  NormalizeColor is applied to color (divide by 255, subtract mean)
  opacity: sigmoid(raw_logit_opacity) -> (0,1)
  scale:   exp(log_scale) -> actual scale
  quat:    normalized, positive real part enforced

Output:
  - Per-point feature vectors of dim 768 (from the first decoder level, dec_channels[0])
  - Accessed via Point["feat"] after backbone forward pass

Source location: /mnt/Data2/liyan/SceneSplat/pointcept/

Key classes:
  pointcept.models.point_transformer_v3.point_transformer_v3m1_base
    - PTv3 backbone
    - forward(data_dict) takes a dict with coord, feat, offset/batch, grid_coord
  pointcept.models.utils.structure.Point
    - Dict subclass that holds point cloud data
    - Point.serialization(...) for space-filling curve ordering
    - Point.sparsify(...) for spconv SparseConvTensor

To use just the backbone (not the full LangPretrainer wrapper):
  - Strip 'module.' prefix from state_dict keys when loading
  - Load only backbone weights (strip 'backbone.' prefix as well, or load backbone directly)
  - Call backbone.forward(data_dict) where data_dict has coord, feat, offset, grid_coord

================================================================================
AUTOENCODER
================================================================================

Checkpoint: /mnt/Data2/liyan/SceneSplat/autoencoder/ckpt/matterport/best_ckpt.pth

Source: /mnt/Data2/liyan/SceneSplat/autoencoder/model.py

Architecture (Autoencoder class):
  in_feature_dim = 768
  encoder_hidden_dims = [512, 256, 128, 64, 32, 16]
  decoder_hidden_dims = [32, 64, 128, 256, 256, 512]

  Encoder: Linear(768->512), BN+ReLU+Linear(512->256), ..., Linear(32->16)
           Then L2-normalize -> 16-dim latent
  Decoder: Linear(16->32), ReLU+Linear(32->64), ..., Linear(512->768)
           Then L2-normalize

  encode(x) -> 16-dim normalized feature
  decode(x) -> 768-dim normalized reconstruction
  forward(x) -> encode then decode (for reconstruction)

Checkpoint is a plain state_dict (OrderedDict), loaded directly:
  model.load_state_dict(checkpoint)

For our use: only need model.encode(feat_768) -> feat_16

================================================================================
INTENDED SCENESPLAT PIPELINE
================================================================================

Key design decision: SceneSplat operates on Gaussian splat attributes, not raw
RGB-D images. Therefore, it naturally fits a **per-map** update pattern:

  1. SplaTAM runs tracking + mapping as normal (geometry only, or with dummy semantics)
  2. After each mapping step (or every N steps), SceneSplat is run on the
     current Gaussian map to produce per-Gaussian 768-dim features
  3. Autoencoder compresses 768 -> 16 dim
  4. These 16-dim features are stored as params['semantic_logits']

This avoids the need for per-frame semantic annotation entirely. There is no
need for projected 2D semantic maps as supervision targets.

Gaussian input preparation (from SplaTAM params):
  coord  = params['means3D']                           [N, 3]
  color  = sigmoid(params['rgb_colors']) * 255        [N, 3]  (uint8 in train, float here)
  quat   = normalize(params['cam_unnorm_rots'...])    [N, 4]  (each Gaussian's rotation)
           NOTE: params['unnorm_rotations'] for per-Gaussian rotations
  scale  = exp(params['log_scales'])                  [N, 1 or 3]
  opacity= sigmoid(params['logit_opacities'])         [N, 1]

  feat = concat([
      color_normalized,   # (color/255 - mean) / std  -> [N,3]
      opacity,            # [N,1]
      quat_normalized,    # [N,4]
      scale,              # [N,3] (tile if isotropic)
  ], dim=-1)              # [N, 11]

Grid coord:
  grid_size = 0.01 or 0.02 (meters)
  grid_coord = floor((coord - coord.min(0)) / grid_size).int()

Batch handling (single scene, batch_size=1):
  offset = torch.tensor([N])  or  batch = torch.zeros(N, dtype=torch.long)

n_cls for scenesplat = 16   (autoencoder latent dim)
topk  for scenesplat = 16   (use all features; no sparse approximation needed,
                              or keep sparse structure with topk=16 for compat)

================================================================================
DIFFERENCES FROM SEMSPLATAM
================================================================================

| Aspect                  | SemSplatam (OneFormer)           | SceneSplatam (SceneSplat)        |
|-------------------------|----------------------------------|----------------------------------|
| Model input             | 2D RGB image per frame           | 3D Gaussian point cloud          |
| When model runs         | Every frame (semantic_annotation)| After mapping steps (per-map)    |
| Feature dim             | 102 (ADE20K classes)             | 16 (autoencoder latent)          |
| Supervision target      | Rendered seman vs oneformer logits| Direct assignment to params      |
| Semantic loss           | Yes (cosine + Hellinger + KL)    | Not needed (direct update)       |
| Sparse representation   | topk=16 of 102 classes           | all 16 features (trivial sparse) |
| Class IDs (seman_cls_ids)| used to index into 102 classes  | 0..15 (identity, always full)    |
| GPU device              | semantic_device (e.g. cuda:1)    | same device as SLAM (cuda:0)     |

   Option B: Every N frames (e.g., every map_every frames)
   Option C: Only at keyframes
   Option D: Only at print_and_save_result / eval time
   -> Recommendation: every map_every frames (matches mapping cadence),
      with a configurable scenesplat_update_freq in the slam config.

3. How to handle the first frame (no Gaussians yet)?
   -> Initialize params['semantic_logits'] as zeros [N, 16] for the first frame,
      then run SceneSplat after the first mapping step.

4. Should the semantic loss be kept (comparing rendered features to SceneSplat output)?
   Option A: No loss — SceneSplat directly writes to params['semantic_logits']
             (no gradient through semantic logits)
   Option B: Keep loss — SceneSplat output is the target, rendered logits optimized to match
   -> Recommendation: Option A for simplicity; Option B if semantic rendering quality matters.
